Course WiFi Mapper

Offline signal survey & map — no internet required

Two ways to log a reading

iOS doesn't let apps read the actual WiFi dBm number directly — but the built-in Shortcuts app can, via its "Get Network Details" action (iOS 17+). Set that up once for exact numbers, or just use the Log tab on its own for a quick subjective rating. Both feed the same map.

Option A — exact dBm via Shortcuts (one-time setup, ~10 min)

  1. Open Files, create a new blank text file named wifi-survey-log.csv (in "On My iPhone" or iCloud Drive), and put exactly this as its only line, then save:
    timestamp,lat,lon,accuracy,ssid,rssi,noise,snr,channel,note
  2. Open Shortcuts → + → name it "WiFi Point".
  3. Add action Get Current Location.
  4. Add action Get Network Details.
  5. Add a Calculate action: tap the RSSI value from Network Details, subtract the Noise value, to get SNR.
  6. Add Format Date (format: ISO 8601) on Current Date, for the timestamp.
  7. Add Text, and build one comma-separated line using the chips for: the formatted date, Latitude, Longitude, Horizontal Accuracy (from the Location), Network Name, RSSI, Noise, your calculated SNR, Channel Number — in that order.
  8. Add Get File pointing at wifi-survey-log.csv, then Combine Text (existing file text, newline, then your new line), then Save File to the same path with overwrite ON.
  9. Add Show Alert displaying the RSSI/SNR chips, so you get instant feedback in the field.
  10. On the shortcut's settings (ⓘ), tap Add to Home Screen — this gives you a one-tap icon. A Back Tap or Action Button binding works too.

This runs entirely offline — Shortcuts, Files, and GPS all work with zero signal. Tap the icon at each spot on the course; it appends one row to the CSV every time. AirDrop or iCloud-sync that file to wherever you run this map viewer, then use the Import tab.

Option B — quick subjective rating (no setup)

Just open the Log tab, get your GPS fix, and tap a 1–5 rating (or "dead zone") at each spot. No Shortcuts needed — good for a fast first pass.

About this page

Everything here runs locally in Safari — no data ever leaves your phone, and no internet connection is used at any point, including map rendering. Add this page to your Home Screen (Share → Add to Home Screen) so it opens instantly, offline, like an app.
